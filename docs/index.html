Season at a glance

Average, best episode and worst episode under every chart.

Matches your theme

Light, dark and high contrast, picked up from AniList itself.

Finds the right season

AniList splits a show into one page per cour. This works out which season each page means — correct on all 134 multi-season shows in AniList's 200 most popular.

Quiet when unsure

No data, or no confident season match? Nothing appears. No empty boxes, no error banners.

Install

Three steps, about a minute

Download the zip 65 KB · always the latest release
  1. Unzip it somewhere permanent

    Chrome loads the extension from that folder every time it starts, so it has to stay put. Documents is fine. Downloads is not.

  2. Open chrome://extensions and turn on Developer mode

    Paste that into the address bar. The toggle is in the top-right corner. On Edge the address is edge://extensions and the toggle is on the left.

  3. Click Load unpacked and pick the folder

    The button only appears once Developer mode is on. Choose the folder you unzipped — the one with manifest.json directly inside it.

Open any anime on AniList and the chart appears at the top of the Overview column, above Relations.

Why not just drag the zip onto the extensions page? Chrome does not allow it. It only ever accepted packed .crx files that way, and it now blocks those too unless they come from the Chrome Web Store — on Windows and macOS there is no self-hosting route at all. Load unpacked is the only way to install an extension that is not in a store, which is why every extension distributed this way asks for the same three steps.

Updating

Replace the folder, hit refresh

Download the new zip, replace the contents of the folder you loaded, then click the refresh icon on the extension's card in chrome://extensions.

Or build it yourself

git clone https://github.com/anas1412/series-graph-for-anilist
cd series-graph-for-anilist
node scripts/package.mjs

Or skip the zip and Load unpacked straight from the cloned folder. There is no build step — plain ES modules and one content script.

Ratings and episode data from Series Graph, which draws on IMDb and its own users. ID mapping from Fribb/anime-lists. Episode counts and air dates from the AniList API.

Not affiliated with Series Graph, AniList, IMDb or TMDB. Collects no data about you — it sends an anime ID and a show ID, both taken from the page URL, and nothing else.
